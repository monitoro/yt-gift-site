개인정보처리방침

시행일: 2026년 11월 25일

1. 앱의 성격

YT Gift는 개발자 본인이 자신의 컴퓨터에서만 실행하는 개인용 프로그램입니다. 별도의 서버를 운영하지 않습니다.

2. Google 사용자 데이터의 사용

  • YouTube Data API 권한(youtube.force-ssl)은 로그인한 본인 계정으로 이벤트 영상에 구독·좋아요·댓글을 남기고, 내 댓글과 그 답글을 확인하는 데에만 사용합니다.
  • 인증 토큰과 앱 데이터는 사용자의 컴퓨터에만 저장되며, 본인만 읽을 수 있도록 보호됩니다.
  • Google 사용자 데이터를 판매하거나 광고에 사용하거나 제3자에게 전달하지 않습니다.

3. 보관과 삭제

사용자는 언제든 앱에서 로그아웃하거나 Google 계정의 서드파티 액세스에서 권한을 취소할 수 있으며, 로컬에 저장된 데이터는 직접 삭제할 수 있습니다.

4. Google API 서비스 사용자 데이터 정책

YT Gift가 Google API에서 받은 정보를 사용하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
